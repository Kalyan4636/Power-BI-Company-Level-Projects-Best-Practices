# Data Dictionary

The sample dataset is fictional and intended only for demonstration.

- **Date**: Timestamp of an interaction.
- **Campaign**: Campaign name.
- **Channel**: Communication method (`Call`, `SMS`, or `Email`).
- **Caller ID**: Source identifier; sample values are illustrative.
- **Destination**: Destination/contact identifier; sample values are illustrative.
- **Status**: Interaction state (`Completed`, `Pending`, or `Failed`).
- **Response Time (min)**: Response duration in minutes; blank when not applicable.
- **Agent**: Fictional agent name.
